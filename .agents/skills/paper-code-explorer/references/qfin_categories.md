# Quantitative Finance Categories on arXiv (`q-fin`)

| Category | Domain & Research Focus |
|---|---|
| **`q-fin.TR`** | **Trading and Market Microstructure:** Order book modeling, market impact, execution algorithms, optimal liquidation, high-frequency trading (HFT), bid-ask spread dynamics. |
| **`q-fin.PM`** | **Portfolio Management:** Asset allocation, factor investing, risk parity, mean-variance optimization, alpha generation, regime-switching models. |
| **`q-fin.RM`** | **Risk Management:** Value-at-Risk (VaR), Expected Shortfall (CVaR), tail risk, margin requirements, stress testing. |
| **`q-fin.ST`** | **Statistical Finance:** Empirical properties of financial markets, fat tails, volatility clustering, stochastic volatility, GARCH models. |
| **`q-fin.CP`** | **Computational Finance:** Monte Carlo methods, PDE solvers for derivatives, finite difference schemes, numerical optimization. |
| **`q-fin.PR`** | **Pricing of Securities:** Derivative pricing, Black-Scholes extensions, interest rate term structures, exotic options. |
| **`cs.LG` / `stat.ML`** | **Machine Learning:** Deep reinforcement learning for trading, transformer models for financial time-series forecasting. |
