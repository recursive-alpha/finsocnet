## Usage

Each SVG is self-contained (500×500 px, dark palette, vector scalable) and can be used directly as:
- **GitHub Organization Avatar**: Upload any `.svg` file in GitHub Org Settings > Profile.
- **Repository Badges / Readme Headers**: Include directly in markdown via `<img src="assets/logos/..." width="120" />`.
