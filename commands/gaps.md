FinSocNet lives in `$FINSOCNET_HOME` (run every command with `uv run --project $FINSOCNET_HOME …`).

Run `uv run --project $FINSOCNET_HOME finsocnet kb gap list --status open` and show each question with how often it was asked and its verdict. Offer to explore the top ones.
